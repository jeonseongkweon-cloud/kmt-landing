# 계명태권도 CLASS 문자 발신기 v0.9.0

## 먼저 할 일

1. Supabase SQL Editor에서 `202608300900_10_android_sms_sender.sql` 전체를 실행합니다.
2. Supabase Authentication → URL Configuration → Redirect URLs에 `kmtclass://login-callback`을 추가합니다.
3. WORK9 ZIP을 홈페이지 저장소 최상위 폴더에 덮어씁니다.
4. GitHub 저장소의 Actions에서 `Build CLASS SMS Sender APK` 작업이 완료될 때까지 기다립니다.
5. 완료된 작업의 `KMT-CLASS-SMS-SENDER-v0.9.0` 파일을 내려받아 압축을 풀고 `app-debug.apk`를 관장님 Android 휴대폰에 설치합니다.

## 휴대폰 최초 설정

1. 출처를 알 수 없는 앱 설치를 이번 APK에 한해 허용합니다.
2. 앱을 열어 SMS 권한과 알림 권한을 허용합니다.
3. Google 관리자 로그인에서 `jeonseongkweon@gmail.com`을 선택합니다.
4. `배터리 최적화 제외 설정`을 누르고 허용합니다.
5. `발신기 ON`을 누릅니다.
6. 휴대폰 알림창에 `계명 CLASS 문자 발신기 ON`이 유지되는지 확인합니다.
7. 듀얼 SIM 휴대폰이라면 Android 설정에서 문자 발송 기본 SIM을 먼저 지정합니다.

## 최초 실발송 시험

실제 학부모 번호로 바로 시험하지 마세요. 원생관리에서 시험 학생의 보호자1 번호를 관장님 본인 휴대폰 번호로 임시 변경하고 시험합니다.

1. 문자대기 화면에서 기존 시험 건을 취소하거나 처리 상태를 확인합니다.
2. 시험 학생을 출석 처리합니다.
3. 관장님 휴대폰으로 문자가 도착하는지 확인합니다.
4. 문자대기 화면에서 `대기 → 발송중 → 완료`로 바뀌는지 확인합니다.
5. 같은 출석을 다시 눌러도 문자가 다시 발송되지 않는지 확인합니다.

## 안전 장치

- 한 번에 문자 한 건만 서버에서 잠급니다.
- 발송 결과가 불확실한 건은 자동 재전송하지 않고 실패 상태로 남깁니다.
- 재전송은 관리자 화면에서 직접 확인 후 실행합니다.
- 문자 실패와 관계없이 출석 기록은 유지됩니다.
- 앱을 OFF하면 새 문자 요청을 가져오지 않습니다.
