# 계명태권도 CLASS 회비관리 SYSTEM — 검증 체크리스트 v1.0

## 0. 현재 검증 범위
- Branch: `tuition-system-v1`
- 운영 `main` 미반영
- 운영 Supabase 쓰기 미적용
- 기존 CLASS/STAR 파일 수정 없음
- 현재 검증은 코드/구조 검증이며, 실제 브라우저 로그인 실검증은 별도 수행 필요

## 1. 데이터 연결 검증
1. CLASS 관리자 로그인 상태에서 `/tuition-admin/` 접속
2. 상단 배지 확인
   - 성공: `CLASS 실데이터 읽기전용 · N명`
   - 세션 없음: `샘플 데이터 · CLASS 로그인 필요`
3. 실제 학생 이름 3명 이상 검색
4. 보호자 이름 검색
5. 보호자 전화번호가 상세/문자 화면에 표시되는지 확인

## 2. 확정 상태 검증
- 김태은: 휴원 / 기준일 28일 / 연장 진행중
- 강민준: 휴원
- 이준범: 휴원
- 김예성·김예담: 퇴관 / 과거자료 보존
- 윤유은·윤우진: 퇴관 / 과거자료 보존
- 한정민·한지아: 퇴관 / 과거자료 보존
- 이승재: 퇴관 / 과거자료 보존

## 3. 가족 묶음 검증
- 김우리 · 김나라 · 김사랑
- 이해찬 · 이정빈
- 윤우준 · 윤이현
- 김예성 · 김예담
- 윤유은 · 윤우진
- 한정민 · 한지아
각 가족이 한 가정 카드로 표시되는지 확인

## 4. 회비 입력 검증
- 적용월과 실제 납부일이 별도 필드인지 확인
- 금액 직접 입력
- 결제방법 선택
- 2회 미납 가정에서 과거 미납월 하나만 선택해 납부 처리
- 선택한 월만 해소되고 나머지 미납월은 유지되는지 확인

## 5. 납부일 변경 검증
- 새 기준일 직접 입력
- 변경이력에 이전일 → 새일 저장
- 다음 달에도 새 기준일 유지
- 늦게 납부한 것만으로 기준일 자동 변경되지 않음

## 6. 문자 검증
- 재원생만 문자 작성 가능
- 휴원/퇴관은 차단
- 납부일 +7일 이후 문자대상 표시
- 2회/3회 미납 문구에 횟수 반영
- CLASS 보호자 전화번호 읽기
- 실제 SMS 전송은 아직 하지 않음

## 7. STAR CLASS 회귀 안전검증
아래 기존 기능은 수정 또는 영향이 없어야 함:
- 출석
- STAR 지급
- UNDO
- 음성 인식
- 공동성장
- GLOBAL SPARK 연동

## 8. 통과 기준
- 콘솔 JS 오류 0건
- 실제 CLASS 원생 목록 조회 성공
- 보호자 연락처 조회 성공
- 확정 휴원/퇴관/가족 상태 정확
- 회비 프로토타입 입력/변경/문자 준비 정상
- 기존 CLASS 수업 기능 영향 0건

## 9. 주의
실제 운영 DB 쓰기와 실제 문자 발송은 이 검증 완료 후 별도 단계에서 진행한다.
