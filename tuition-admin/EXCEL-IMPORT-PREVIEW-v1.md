# 계명태권도 회비관리 — 2026 회비대장 이관 미리보기 v1.0

기준 자료: 업로드된 2026년 회비대장 엑셀.
원칙: 이 문서는 이관 후보를 정리하는 미리보기이며 운영 DB에는 아직 반영하지 않는다.

## 집계
- 이름이 기재된 회비관리 가정 후보: 51가정
- 기존 장부 번호는 원본 추적용으로만 보존
- 괄호 숫자는 현재 기준 납부일로 해석
- 금액은 자동 산정하지 않고 실제 받은 금액을 사용자가 직접 입력

## 다음 대조 단계
1. 현재 CLASS `students` 원생명단과 위 51가정 후보를 대조한다.
2. 단일 학생은 이름 정확 일치 시 자동매칭 후보로 표시한다.
3. 형제 표기는 각 학생을 개별 `students.id`에 연결한 뒤 하나의 `tuition_households`에 묶는다.
4. 이름이 모호하거나 현재 CLASS에 없는 학생은 자동 생성하지 않고 `확인 필요`로 남긴다.
5. 연장 표기는 사진의 최신 수기 기준일을 확인하기 전까지 기존 괄호 숫자를 덮어쓰지 않는다.
