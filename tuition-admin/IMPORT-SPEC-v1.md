# 계명태권도 회비관리 — 엑셀 이관 규격 v1.2

## 목적
기존 회비 엑셀 자료를 안전하게 이관한다. 기존 CLASS 원생은 이름만으로 새로 생성하지 않고 `students.id`와 매칭한다.

## 1차 권장 열
- 학생명
- 학생코드(있으면 최우선 매칭)
- 수업부
- 보호자명
- 보호자전화
- 월회비
- 정기납부일(1~31)
- 결제수단(계좌/울산페이/카드/현금/기타)
- 최근납부일
- 최근납부금액
- 적용월(YYYY-MM)
- 미납횟수
- 메모

## 매칭 우선순위
1. 학생코드 정확 일치
2. 학생명 + 보호자전화 일치
3. 학생명 + 수업부 일치
4. 이름만 같은 경우 자동확정 금지 → 수동 확인 목록

## 가족/형제 처리
같은 보호자 전화번호를 가진 학생은 가족 후보로 표시하되 자동 병합하지 않는다. 관리자가 확인한 뒤 `tuition_households`로 묶는다.

### 확인 완료 가족 매핑
- 기존 엑셀 표기 `우,나,사(15)` = `김우리`, `김나라`, `김사랑`
  - 세 학생은 **한 가정**으로 확정한다.
  - 형제/자매 할인 적용 가정이다.
  - 할인 금액은 시스템이 계산하지 않는다.
  - 실제 납부금액은 관장님이 매 회차 직접 입력한다.
  - 회비카드는 `김우리 · 김나라 · 김사랑 가정`으로 표시하고 내부적으로 세 학생 각각의 `students.id`를 연결한다.

- 기존 엑셀 표기 `해찬,정빈(20)` = `이해찬`, `이정빈`
  - 두 학생은 **형제이며 한 가정**으로 확정한다.
  - 회비카드는 `이해찬 · 이정빈 가정`으로 표시한다.
  - 내부적으로는 두 학생 각각의 `students.id`를 연결한다.
  - 금액은 자동계산하지 않고 실제 납부금액을 관장님이 직접 입력한다.

## 안전 규칙
- students/enrollments/attendance/STAR 데이터 수정 금지
- 이관 전 미리보기 제공
- 중복 행/금액 오류/날짜 오류 별도 표시
- 확정 전 DB 저장 금지
- 이관 후 원본 행 번호와 결과를 로그로 남길 것
- 형제할인 금액 자동계산 금지
- 실제 납부금액은 사용자가 직접 입력

## 상태 계산 원칙
- 정상: 이번 청구월 납부 확인
- 납부 임박: 납부일 전 지정 기간
- 경과: 납부일은 지났으나 미납 1회 미만의 안내 단계
- 미납 1회/2회/3회+: 연속 미납 청구월 기준
- 휴관/퇴관 원생은 active=false 처리하되 과거 납부기록은 보존
