# 계명태권도 CLASS 회비관리 SYSTEM

## 개발 격리 원칙

이 디렉터리는 회비관리 전용 개발 영역이다.

- STAR CLASS 관련 파일 수정 금지
- `class/`, `class/live/`, `class/growth/`, 출석/STAR/음성/UNDO/GLOBAL SPARK 코드는 수정하지 않는다.
- 공통 원생정보는 향후 학생 ID/이름/수업부/보호자 연락처를 읽는 용도로만 연결한다.
- 회비 데이터는 `tuition_` 접두어를 가진 전용 테이블로 분리한다.
- 회비관리 오류가 STAR CLASS 수업 실행에 영향을 주지 않는 구조를 유지한다.
- 기존 `pay/`는 학부모용 결제·환불 안내 페이지이므로 회비관리 관리자 화면으로 재사용하지 않는다.

## 확정 운영 규칙

- 관리 기본단위: 가정. 형제는 한 가정에 여러 학생을 연결한다.
- 실제 회비 금액은 사용자가 직접 입력한다. 부분납부 기능은 없다.
- 적용월과 실제 납부일을 분리 저장한다.
- 기준 납부일은 사용자가 직접 변경할 때만 바뀌며, 변경된 날짜는 이후 매월 계속 적용한다.
- 늦게 납부해도 기준 납부일은 바뀌지 않는다.
- 미납은 월별로 계산하여 1회 미납, 2회 미납, 3회 미납 등으로 표시한다.
- 납부일 + 7일부터 문자 준비 대상으로 표시하되 자동 발송하지 않는다.
- 휴원/여행/퇴관/휴관을 지원한다. 해당없음 월은 미납 계산에서 제외한다.
- 학생/형제/부모/결제자/울산페이 가림 표시명으로 통합 검색한다.
- 울산페이 결제자는 한 가정에 여러 명 등록할 수 있다.

## 초기 화면 목표

메인 대시보드에서 재원생/가정 수, 정상, 임박, 미납, 미납 회차, 문자 대상, 울산페이 빠른찾기, 오늘 받은 회비를 한눈에 확인한다.
